## 폴더 정리

최상위 파일은 README.md·REPORT.md 두 개로 정리했다. 서비스 실행에 필요한 코드·설정·검사 도구는 service/ 내부에서 기존 상대 배치를 유지한다. 설명·평가·출처 자료는 docs/, 제출본 검증 도구는 tools/submission/에 모았다. 아래 실행 경로가 현재 기준이며 앞선 검사 기록의 npm·기능 검사 명령은 service/ 안에서 실행한다.

- 앱 실행: `cd service` 이후 `npm ci`, `npm run dev`.
- 제출본 검사: 저장소 루트에서 `node tools/submission/verify.mjs`.
- 서비스 실행 안내: [docs/service/README.md](../service/README.md).

폴더 이동 후 `service/`에서 프로덕션 빌드·TypeScript 검사, lint, 평가 도구 테스트25개를 다시 실행해 모두 통과했다. 서비스·빌드 파일92개의 원본 바이트 일치도 확인했다. 제출본 내부 파일 링크와 앵커 검증도 통과했다. 루트 Markdown 두 파일의 해시는 Windows 체크아웃의 CRLF를 LF로 정규화하고, 나머지 증거 파일은 바이트 그대로 검증한다.
